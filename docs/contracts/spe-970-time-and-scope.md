# SPE-970 · 时间与重复范围合同

决策票：[决定全天、时区与重复系列的时间和修改范围合同](https://linear.app/icecoke/issue/SPE-970)。2026-10-01，Leo 对五组业务方案实际回复“按建议”，确认下列目标行为。公开能力依据为 [Calendar 研究][R1]、[Reminders 研究][R2]、[MCP 与运行基线研究][R3]；覆盖与限制术语沿用 [CONTEXT](../../CONTEXT.md)。

本文件是已确认的目标合同，供后续实现与独立验收使用。此次没有实现或实测本合同，也没有启动产品、安装或切换 MCP、访问个人对象。已有源码路径、API 声明和保存结果均不能证明产品已达成本合同。标识符与查询协议交 [决定查询窗口、分页、标识符与冲突去重合同][D1]，具体输入/输出格式交 [决定 MCP 工具分组、输入结果合同与旧工具兼容][D2]，原子性、重试与恢复算法交 [决定批量、移动、重试与 undo/redo 的状态不变式][D3]；本票不预定它们的架构。

## 一页不变式与状态表

以下是领域约束与状态描述，不是已实现的 wire 字段、错误码或状态机。

| 不变式 | 必须保持的结果 |
| --- | --- |
| I1 时间意义 | 日期、带时间的当地钟点、绝对时刻和浮动时间分开；展示换算不能改写保存意义。 |
| I2 时区 | 明确地区按该地区解释；新输入未给地区按 Mac 设定解释并回显；显式浮动不补固定时区。 |
| I3 日期 | 全天结束日期含完整末日；日期型待办不暗加午夜时间或通知；无日期待办不加期限。 |
| I4 时长与歧义 | 新建定时日程缺时长/结束时间先问；已有定时日程仅改开始保留实际经过时长；意义不明、DST 不存在/出现两次先问，不自动挪动。 |
| I5 重复规则 | “每月最后一天”不等于“每月31号”；短月规则在创建/修改时确定一次，之后沿用，不擅自改日。 |
| I6 范围与目标 | 重复改删必须明确只这次、从这次起及以后、整个系列；实例/系列边界未证实不写入；Calendar 与 Reminders 分别判定可达范围。 |
| I7 结果与身份 | 请求回显、已保存动作、实际范围、通知、下一实例和身份各按证据返回；旧/新/未知身份不伪装稳定；下一实例未知不重放已保存的完成动作。 |

| 当前条件/阶段 | 允许推进 | 对外结论 |
| --- | --- | --- |
| 时间意义、重复范围、实例或短月规则未确定 | 仅澄清与读取候选，不写入 | 需澄清，列出缺项与候选，不使用默认值代答。 |
| 公开 API 不支持，或当前尚未实现 | 不执行替代写入冒充目标 | 分别返回不支持能力或尚未实现，说明受限动作。 |
| 来源受限或权限不足 | 不转移对象或改范围绕过限制 | 明确限制所属来源/权限；若已写入部分内容，同时返回已知实际结果。 |
| 目标、意义、范围与可达能力已确定 | 才可按已确认请求写入 | 执行前回显解释、目标与请求范围；不是写入完成证明。 |
| 同一目标收到在途第二请求，或写前发现外部修改/删除 | 不凭旧基线继续写，不覆盖外部变更或误写新实例；先重查/澄清 | 若前一请求已有写入，保留实际已知结果并交状态与恢复合同；不承诺锁或原子算法。 |
| 保存/删除成功，范围或后继仍待确认 | 读取实际结果，不自动重复写入 | 只报告已知动作成功；范围、身份、下一实例或通知未知分别保留。 |
| 实际结果与请求一致且有对应证据 | 报告该项完成 | 不扩大成同步、通知、其他来源或整个系列已验证。 |
| 失败、部分达成或结果不明 | 交后续状态合同处理；不盲目重放 | 返回已知达成项、失败/未知项和受影响身份，不写成全部成功或全部未发生。 |

## 时间输入与回显

| 输入意义 | 解释与回显合同 |
| --- | --- |
| 明确地区的定时时间 | 保留约定地区与钟点。每周“新加坡上午9点”的会议以 `Asia/Singapore` 为锚；旅行伦敦仅改变当地显示，不能改成伦敦上午9点。回显约定地区时间、当地换算及对应日期/偏移。 |
| 新输入未写地区 | 在没有显式浮动要求时，按解释该请求时 Mac 的时区设定解释，并回显实际采用的地区；不得仅输出“本地时间”。后续 Mac 设定改变不能静默重解释已有约定。 |
| 显式浮动时间 | 保留当地钟点随所处时区解释的意义；不能将原生 `timeZone=nil` 伪装成固定 Mac 时区，也不能为其宣称唯一绝对时刻。若给出换算，标明当次采用的解释地区。 |
| 明确绝对时刻或数值偏移 | 保留已给绝对时刻。数值偏移不能冒充地区的 DST 规则；若重复安排或改时区时仍无法确定要保留绝对时刻还是地区钟点，先澄清。 |
| 只改已有对象的非时间字段 | 保留原来的日期精度、时区/浮动意义与时间值；不能因本次未带地区而重写成 Mac 时区。 |

回显必须让调用者核对：原请求的时间意义、解释后的日期/钟点、约定地区或浮动状态、展示地区，以及定时日程的结束时间/实际时长。相对日期或“今天9点”等输入应回显解析后的完整日期；如果信息不足以唯一解释，先询问。读回缺少原始时区或日期精度时返回未知，不能以格式化值补造源语义。[R1][R2][R3]

修改时区不能自动等同于移动日程。若用户没有说清保留绝对时刻还是保留当地钟点，先询问；macOS 13+ 修改 `timeZone` 不再改变绝对时刻，也不能依赖单独设置该属性实现业务上的改时。[R1]

### 全天、日期型与无日期

“1至3号休假”覆盖1、2、3号的完整民用日期。对外表达含首日和末日，不用午夜绝对时刻代替日期；查询和读回也必须能确认完整3号。EventKit 适配必须按受支持 macOS 版本核对原生边界：[TN3130](https://developer.apple.com/documentation/technotes/tn3130-changes-to-eventkit-in-macos13-ventura) 说明 macOS 13+ 全天 `endDate` 为末日23:59:59，不能套用统一的“结束瞬间不包含”假设。[R1]

“3号交材料”这样的日期型待办保留日期精度，不补 `00:00`、固定时区或午夜通知；“记得整理资料”这样的无日期待办不加到期日。到期日期与 alarm 是独立意图，设置日期不等于已安排通知。提醒事项的 `startDateComponents`、`dueDateComponents` 分开保留；Gregorian、日期精度及各自时区按公开 API 要求处理，不能用一次 `Date` 转换抹掉日期型或浮动语义。due 时区不由 item/start 时区代替。[R2]

### 时长与 DST

新建定时日程必须有可确定的结束时间或时长；只给开始时间时先询问，不擅定默认时长。已有定时日程仅改开始时保留原实际经过时长，即原结束绝对时刻减原开始绝对时刻；若同时明确新结束时间，则使用用户的新范围。该规则不用于把全天日期折算成固定24小时，也不用于推断浮动时间的唯一绝对时长。

不存在的当地时刻不能自动移到下一个合法时刻；同一当地时刻出现两次时不能自动选择第一次或第二次。先给出需确定的日期、地区与候选时刻，等用户明确；用户已用有效偏移/绝对时刻消除歧义时保留其选择。地区与偏移冲突、跨日结束意义不明、转换全天/定时含义不明也须澄清。重复展开遇到这些情况同样不能擅自挪动；公开 EventKit 没有 gap/fold 策略参数，实际来源行为必须另验，未验证前不能承诺展开结果。[R1]

## 重复规则与修改/删除范围

| 业务范围 | Calendar 目标与边界 | Reminders 边界 |
| --- | --- | --- |
| 只改/删这次 | 唯一确认的原始单次实例；可对应 `.thisEvent`。修改后开始日期不能替代原始 `occurrenceDate`。 | save/remove 没有 `EKSpan` 或 Calendar 的 occurrence 定位接口；不能借此承诺等价的单次范围。 |
| 从这次起及以后 | 包含当前实例；可对应 `.futureEvents`。更早的实例不在请求范围内；锚点必须已证实。 | 不能借 Calendar 的 future 范围或完成后的推进推导此范围支持。 |
| 整个系列 | 没有原生 all-series span；组合操作必须先证实系列起点、实例归属与可达边界，再验证实际结果。 | 不能借用 Calendar 组合操作承诺整个系列改删；公开能力及来源结果不足时明确限制/未知。 |

用户对重复对象没有说明范围时先问，不用已有工具的缺省 span 代答。非重复对象不凭空制造系列范围。用户已经明确的范围只解决业务选择，不能代替来源能力、实例身份和实际影响的证明。[R1][R2]

Calendar 的 `event(withIdentifier:)` 不保证在所有 macOS 情况下取得系列起点；首实例被修改、detached、历史拆分或同步后的系列边界必须核实。不能将按 ID 查到的对象直接称为 master 并从它应用 `.futureEvents`，然后宣称整个系列完成。只读查询窗口、空结果或数量相符也不足以证明全系列边界；单个 EventKit 查询还有四年窗口限制。[R1][R3]

实例定位使用保存前的原始发生时间及其既有时间意义；新开始时间、请求的新时区或展示时区不能改变定位锚点。日期型选择只在候选唯一且原始日期所属地区已确定时可用于确认实例；同日多实例、跨日移动的 detached、旧 ID 失效或多候选时先澄清/重查，不取第一个命中。具体 locator、系列身份与查询完整性协议留给 [决定查询窗口、分页、标识符与冲突去重合同][D1]。

每月最后一天与每月31号分别表达。`daysOfMonth=-1` 的公开规则可以表示月末，但当前 parser 只接受1…31，尚不能据现有 MCP 输入宣称月末创建已支持；31号表达为31，来源对短月的实际展开尚未实测。[R1] 创建或修改可能遇短月的规则时，一次确认其业务处理，之后沿用；Leo 本次确认的是这个确认流程，没有替某个虚构安排选“跳过”或“移到月末”。既有规则的短月意义无法确定时先澄清；所选处理无法准确表达或来源未支持时返回相应限制，不能换成近似规则。

重复规则必须能完整表达被请求的意义。不能静默忽略高级规则字段、把现有复杂规则降成当前 MCP 子集，或把规则不生成的日期伪造为“已删除实例”。间隔/次数必须为正；截止日期与次数同时给出、结束边界或计数含义不明时拒绝冲突或先澄清，不按 parser 优先级代选。未请求的例外、排除和已修改实例不能无声丢弃；可达范围与请求外影响未确认前不写入，说明限制不能代替授权。若只能执行不同或较小动作，先取得相应明确选择，不能凭已告知就执行；也不能以规则保存成功声称完整系列等价。[R1][R2]

## 错误、需澄清与身份返回

需澄清用于用户意图或目标有多个合法解释：重复范围缺失、时间意义不明、DST 歧义、缺时长、短月规则未定、实例多候选。无效日期、无效地区、倒序定时范围、非法规则值或互斥输入冲突须在写入前拒绝，不能归一化成另一个合法请求。来源只读/拒绝某字段、TCC 权限不足、公开 API 不支持、当前尚未实现和效果尚未验证分别表达；不能混成“找不到”。错误码与结果字段由 [决定 MCP 工具分组、输入结果合同与旧工具兼容][D2] 决定，可恢复语义由 [决定批量、移动、重试与 undo/redo 的状态不变式][D3] 决定。

结果保留请求范围与实际已知范围的区别。只在证据支持的粒度报告完成；保存成功不等于指定实例/未来/整个系列均正确，也不等于同步完成、通知触发或下一实例已生成。部分结果和未知必须能被调用者区分，不能只返回请求的 span、旧 ID 或统一成功文案。[R1][R2][R3]

身份返回应区分请求时的目标与写后实际读回的对象：保留旧身份作为请求依据，返回已证实的新身份及其关联；无法证实关联就返回未知。ID 因移动、拆分、同步或重复推进变化时不能伪造稳定性；同名、相同 external ID 或相同开始日期不足以唯一证明是原对象。删除后的请求 ID 是被操作目标的记录，不是仍可用的对象身份；标识符协议留给 [决定查询窗口、分页、标识符与冲突去重合同][D1]，具体返回字段留给 [决定 MCP 工具分组、输入结果合同与旧工具兼容][D2]。

重复提醒的完成动作与保存后的 `isCompleted`、due、下一实例观察分开。只有读回证据支持时才确认后继；规则推算的日期不能冒充已生成实例。已保存完成但下一实例未知时不重放完成，避免再次推进；也不能因原 ID 此时指向下一次而对其执行重开/恢复并声称恢复了刚完成那次。身份协议留给 [决定查询窗口、分页、标识符与冲突去重合同][D1]，完成/重新打开的恢复方案留给 [决定批量、移动、重试与 undo/redo 的状态不变式][D3]。[R2][R3]

以下均未执行。后续按 [验证规则](../agents/validation.md) 先确认 binary 路径、版本、commit、同一长驻 MCP 会话和 TCC；由主控按授权写入可识别的独立测试集合，记录创建 ID、独立系统回读并只清理本轮对象。作者与 `gpt-6.1-sol / ultra` reviewer 独立，先审上述不变式，再审完整行为链。

| 验收面 | 必须保留的证据与通过条件 |
| --- | --- |
| 约定地区、显示与浮动 | 新加坡9点每周会跨伦敦展示、Mac 时区变化、显式浮动、既有对象非时间更新；约定意义保持，展示换算可核对，浮动不伪固定。 |
| 全天与待办日期 | 单天/1至3号、跨DST民用日期、日期型/无日期待办、start/due各自时区；日期范围和组件精度正确，无新增午夜通知或期限；按 macOS 版本读回原生字段与 UI。 |
| 时长与DST | 缺时长未写入、已有定时仅改开始保留实际时长、gap/fold和偏移冲突未静默移动；分别记录解析、保存值和系统显示，不能只查 formatter。 |
| 月末与短月 | 月末、31号、闰年2月、已选短月规则沿用；核对原生规则与来源实际展开，未表达/未验证组合明确限制。 |
| this/future/all | 原始及跨日 detached、首实例改删、系列拆分、例外/排除、终止/count；读回范围前后边界、受影响实例与身份，验证请求外实例，不能只凭保存或总数。 |
| 重复提醒完成与身份 | 完成/重开前后 due、rules、list/source、旧/新ID与下一实例；未知不重放，不把另一实例当成恢复目标；来源结果分别记录。 |
| 限制与不确定结果 | 来源拒绝、权限撤销、外部改删、保存后读回失败及部分影响；返回实际已知动作和未知，不误称无副作用或全成功。通知和远端同步另有独立证据。 |
