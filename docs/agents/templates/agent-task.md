# 派工 / 交接

- Issue 标题与链接：
- Mode：Research / Implement / Verify / Independent review
- 模型与真实 effort：
- 基线 commit / 工作区 / branch：
- 目标与不可扩大边界：
- 文件所有权（read/write；共享文件唯一 writer）：
- 已决合同与 blocker：
- 完成标准：
- 验证命令 / 表面 / 通过条件：
- 授权（Git、凭据、真实对象、签名、release、安装；未授权项列明）：
- 返回：改动、证据、命令/退出状态、passed/skipped/not-run、剩余项及下一精确动作。

执行者不递归派工、不自动 commit/push；作者不能同时担当独立 reviewer。
